Three Lakes Music is where I build instruments, write the firmware that runs them,
and publish the reference material that falls out of doing both.

I'm a senior software engineer working in embedded systems. Before that I studied
German, then music, and spent a stretch as a PLC programmer doing factory
automation — less unrelated than it sounds, since all three are about systems that
have to work in the real world, on time, every time. I play guitar, piano, and
modular synths, and I've been building Eurorack modules long enough to have
opinions about the firmware underneath them.

## Sound Byte Labs

An open-source firmware library for embedded audio on ARM.

The premise: getting a voice running on a microcontroller should take an evening,
and the code you build on should be one you'd be comfortable shipping in a
product. Those two goals usually pull against each other. Sound Byte Labs is an
attempt at both — a small, well-documented API over a codebase with real
architecture behind it.

It owes an obvious debt to Mutable Instruments, whose willingness to publish
high-quality designs is a large part of why any of this is possible.

**Status:** in development.

## Reference sheets

Working datasheets on the things I keep having to re-derive — perspective
construction, compositional armature, filter response. Each one states the rule,
gives the derivation, names the failure mode, and ends with a criterion you can
check your own work against. Figures are generated from tested math rather than
drawn by hand.

**Status:** in progress; first sheets publishing soon.
